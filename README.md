# beecrowd Solutions 🚀

This repository contains my personal solutions to competitive programming and algorithmic challenges from the **beecrowd** platform (formerly known as URI Online Judge).

---

## 📌 About beecrowd
[beecrowd](https://judge.beecrowd.com/) is an online learning and competitive programming platform widely used to practice problem-solving, data structures, and algorithms. It features a rich collection of challenges ranging from basic syntax exercises to advanced computer science topics.

---

## 💻 Languages Used
Problems are solved mainly using:
- **C**: Used for low-level performance, memory management, and structured algorithmic problem solving.
- **Python**: Used for rapid prototyping, string manipulation, and clean implementation of mathematical algorithms.

---

## 📂 Structure
Each file corresponds to a problem solved on the platform, following the naming convention:
`[Problem-ID]-[Problem-Name].[extension]`

For example:
- `1000-Hello-World.c`
- `1001-Extremely-Basic.py`

---

## 📝 Note on Output Text
Since beecrowd originated as a Brazilian competitive programming platform (URI Online Judge), the required prompt outputs and system messages across many problems (such as status verdicts, geometric labels, and confirmation messages) are standardized in **Portuguese** (e.g., `Perimetro`, `Sao Multiplos`, `Aluno aprovado`). Consequently, the output strings in the solution files directly mirror this convention to ensure exact presentation compliance with the platform judge.
